# Sistem de Gestiune și Administrare pentru Salon de Manichiură și Academie de Nail Art

Acesta este depozitul aferent proiectului la disciplina **Baze de Date** (Anul 3, 2026-2027). 
Proiectul presupune dezvoltarea unei baze de date pentru optimizarea fluxurilor operaționale dintr-un salon de înfrumusețare care funcționează și ca academie de formare profesională.

## Funcționalități principale
- **Gestiunea clienților și cursanților:** Istoric programări, reduceri (onomastice/fidelitate), alerte medicale (alergii).
- **Gestiunea personalului:** Evidența tehnicienilor și trainerilor, program de lucru, concedii și acreditări profesionale.
- **Operațional Salon & Academie:** Programări pentru servicii, asocieri cu tehnicieni, gestiunea înscrierilor la cursuri.
- **Inventar și Sterilizare:** Gestiunea stocurilor (separat pentru salon și academie), evidența aparaturii și registrul digital de sterilizare.

## Structura depozitului
- `docs/` - Documentația oficială a proiectului.
- `db/schema/` - Scripturi de creare a tabelelor, constrângerilor și indecșilor.
- `db/seed/` - Scripturi pentru popularea bazei de date cu date de test.
- `db/queries/` - Interogări SQL pentru rapoarte și statistici.
- `db/diagrams/` - Modelul conceptual (Diagrama ER).
- `app/` - Aplicația practică și scripturile de conectare.
