# Laborator Java - Clase și Moștenire

Acest folder conține implementări de bază în Java pentru exersarea conceptelor de programare orientată pe obiecte: crearea claselor, încapsularea datelor și moștenirea.

## Fisiere incluse:
* **`ContBancar.java`** - Clasă de bază care definește un cont bancar simplu (adăugare, extragere fonduri și afișare sold).
* **`ContBancarExtins.java`** - Clasă derivată din `ContBancar` care introduce conceptul de dobândă anuală și capitalizare lunară.
* **`TestCont.java`** - Clasa principală (`main`) pentru testarea logicii conturilor bancare.

## Cum se rulează?
Clasa executabilă este `TestCont.java`. Poate fi rulată din orice IDE de Java (IntelliJ, Eclipse) sau direct din linia de comandă.
