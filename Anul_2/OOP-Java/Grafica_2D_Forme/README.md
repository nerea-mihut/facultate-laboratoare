# Grafică 2D și Forme Geometrice - Java

Acest folder conține o serie de aplicații practice pentru desenarea, generarea și manipularea formelor geometrice în Java, utilizând concepte OOP precum tablourile de obiecte și instanțierea multiplă.

## Structura Proiectului & Cerințe

* **Forme Geometrice de Bază:** Conține definițiile și logica de desenare pentru mai multe clase specifice (`Cerc`, `Patrat`, `Linie`, `Triunghi`, `Poly`, `Imagine`).
* **Generare Multiplă (Clasa Mark):** Implementarea și utilizarea clasei `Mark` pentru a genera automat un set de 50 de figuri pe ecran.
* **Gestiunea prin Tablouri:** Crearea unui tablou de obiecte care stochează instanțele formelor geometrice, urmată de parcurgerea acestuia pentru afișarea lor simultană.

## Cum se rulează?
Codul necesită un mediu de dezvoltare Java (IntelliJ IDEA, Eclipse) configurat pentru interfețe grafice (Swing/AWT). Rulați fișierul principal (care conține metoda `main`) pentru a deschide fereastra și a vizualiza formele generate.
